\begin{abstract}
    Operational Modal Analysis (OMA) is a powerful technique which allows engineers to model vibrations in complex man-made structures based on measurement data gathered from accelerometer arrays. In this work, we present our implementation of OMA in the Senmos monitoring platform as well as potential applications. Our main contribution is improved ease of use compared to traditional software solutions for OMA. We compare results obtained from our OMA implementation with the more traditional modeling technique of finite element analysis (FEM).
\end{abstract}

\section{Introduction}

Operational Modal Analysis (OMA) encompasses a set of techniques developed to calculate and visualize modal vibrations of structures from real-world measurements. In this article we explore OMA techniques recently added to the Senmos cloud platform, and the ways in which they can be used to gain a better understanding of how structures like bridges, chimneys and wind turbines interact with external forces. 

Every structure has a set of natural frequencies which it tends to vibrate at when excited by an outside force. For instance, if a swing is lifted upwards and then let go, it swings back and forth at a certain rate which is determined by the length of its ropes. The same phenomenon is at play with more complex structures, although there is no easy way to calculate the natural frequencies based on physical characteristics of these structures. For each natural frequency $f_k$, there is also an associated mode shape $\bm{\phi}_k$ which dictates the relative amplitude and phase (encoded as a complex number) at which each measurement point on a structure oscillates. A damping ratio $\zeta_k$ quantifies how quickly oscillation in a specific mode decays, relative to the natural frequency $f_k$. For instance, a damping ratio of $0.01$ indicates that after one oscillation, the amplitude has decreased by $0.01 \times 2\pi \approx 6.3\%$.

An OMA technique is an algorithm which converts measurement signals gathered from arrays of accelerometers placed at various points on a structure into natural frequencies, damping modes, and mode shapes (see Figure~\ref{fig:oma-schematic}).

\input{figures/oma_schematic.tex}

Natural frequencies definition, damping modes definition, mode shapes definition. Note that OMA algorithms are windowed algorithms; they produce results for a window of measurements with a specified length, typically chosen on the order of 30 minutes to a few hours.

The variety of external forces which can interact with a structure greatly complicates the task of separating physical characteristics like natural frequencies from temporary forced vibrations caused by these forces. Due to this, every OMA algorithm requires some form of calibration to give accurate results. For instance, algorithms based on frequency-domain decomposition (FDD) produce transient natural frequencies under most circumstances. Fortunately, Senmos exposes methods by which even a non-expert can quickly identify which natural frequencies produced are transient and which are genuine.

The remainder of this article is structured as follows: Section~\ref{sec:theory} discusses theoretical background. Section~\ref{sec:practical} discusses the high level organization of our OMA implementation, together with its practical applications in structural health monitoring. We also present a concrete example of a wind-turbine monitoring project. Section~\ref{sec:further} relates OMA to other modeling techniques and argues for a holistic approach using multiple modeling techniques. Section~\ref{sec:conclusion} gives concluding remarks. The practically-oriented reader who is already familiar with the rudiments of OMA can skip Section~\ref{sec:theory}.

\section{Theoretical Backgound}\label{sec:theory}

OMA techniques can be broadly classified into frequency-domain decomposition (FDD) methods, and stochastic subspace identification (SSI) methods, which we will discuss in turn. % TODO: Refine

\subsection{FDD-Based Methods}\label{sec:fdd}

FDD-based methods were introduced in the early 2000s~\cite{Brincker2000OutputonlyMA,Brincker2001DampingEB} and operate on the frequency domain representation of measurement signals, typically the power spectral density (PSD) matrix $\mathbf{G}_{yy}\left(\omega \right)$ which collects all cross-spectral power densities.

Under mild conditions, the input PSD matrix ${\mathbf{G}}_{\mathrm{xx}}\left(\omega \right)$ can be related to the output PSD matrix ${\mathbf{G}}_{yy}\left(\omega \right)$ (corresponding to the actual sensor measurements) by the following equation:
\[
\mathbf{G}_{yy}\left(\omega \right) = 
\mathbf{H}^{\dagger}\left(\omega \right)\mathbf{G}_{xx}\left(\omega \right)\mathbf{H}\left(\omega \right)
\]
where $\mathbf{H}(\omega)$ is the unknown Frequency Response Function (FRF) matrix which determines the system-environment interaction.

At a given frequency $\omega$, only 1-2 modes will typically contribute significantly to the system output. Assuming that external forces have a PSD corresponding to white noise, one can derive the following equation~\cite{Brincker2000OutputonlyMA}: 
\[
\bar{G}_{yy}(\omega)
=
\sum_{k}
\left(
\frac{d_k \bm{\phi}_k \bm{\phi}_k^{T}}{j\omega-\lambda_k}
+
\frac{\bar{d}_k \bar{\bm{\phi}}_k \bar{\bm{\phi}_k^{T}}}
{j\omega-\bar{\lambda}_k}
\right)
\]
where $\lambda_k = 2\pi f_k\left(-\zeta_k + j\right)$, $d_k$ determines the relative contribution of each mode, and the sum is over all significant modes.

Supposing that natural frequencies can be clearly distinguished, it is easy to see that $\bar{G}_{yy}(\omega) \to \frac{d_k \bm{\phi}_k \bm{\phi}_k^{T}}{2\pi f_k\zeta_k}$ as $\omega$ approaches some natural frequency (measured in angular units) $2\pi f_k$. In this case $\bm{\phi}_k$ will correspond to the largest left singular vector of $\bar{G}_{yy}(\omega)$. Furthermore, since $\bar{G}_{yy}(\omega)$ is approximately a rank-1 matrix under these conditions, the corresponding singular value (SV) is much larger than the rest of the spectrum. By a similar analysis, one can show that if two (or more) natural frequencies are close to one another, the corresponding mode shapes are proportional to the largest two left singular vectors of $\bar{G}_{yy}(\omega)$ and the corresponding singular values are much larger than the rest of the spectrum.

FDD based methods discretize the frequency spectrum and compute the singular-value decomposition (SVD) at each point. A modal parameter estimation (MPE) plot is then produced, depicting the first few largest singular values (normalized to the $[0,1]$ range relative to the maximum singular value) against the frequency $f$. The first and second scenarios highlighted above will be clearly visible in such a plot as a peak reaching $\approx 1.0$ in the first SV and large peaks in the first and second SVs which together sum to $\approx 1.0$ respectively.

Figure~\ref{fig:sv-plot} shows an MPE plot for our running example of a wind turbine, depicting the peak observed at an isolated natural frequency.

\input{figures/FDD-SV-plot.tex}

Once natural frequencies have been selected, the corresponding mode shapes can be obtained from the SVD decomposition computed for those frequencies, and the damping ratios can be computed from the equations shown above.

\subsection{SSI-Based Methods}\label{sec:ssi}

SSI-based methods~\cite{ssi} can operate on both the time and frequency domains of a system. In this section we focus on SSI-COV, which operates on the time domain and is implemented in Senmos. 

SSI-based methods model the (discrete-time) dynamics of the system using the two linear equations:
\begin{align*}
    \mathbf{x}_{t+1} = \mathbf{A}\mathbf{x}_{t} + \mathbf{w}_t \\
    \mathbf{y}_{t+1} = \mathbf{C}\mathbf{x}_{t} + \mathbf{v}_t
\end{align*}
where $\mathbf{x}_t, \mathbf{y}_t$ are the system state and measurements collected at time $t$ respectively, while $\mathbf{w}_t, \mathbf{v}_t$ are random noise signals caused by external forces and limited measurement precision respectively. They are typically assumed to be white noise.

It is convenient to collect $\{\mathbf{x}_{t}\}_{t=1}^T$ and $\{\mathbf{y}_{t}\}_{t=1}^T$ into $d\times T$ matrices $\mathbf{X}$ and $\mathbf{Y}$.

SSI-COV is based on the covariance matrices $\mathbf{R}_i$, defined for each row of $\mathbf{Y}$. For row $\mathbf{y}^{(i)}$ of $\mathbf{Y}$, the covariance matrix is defined as:
\[
\mathbf{R}_i = \mathbf{y}^{(i)}\left(\mathbf{y}^{(i)}\right)^T
\]

It can be shown that
\[
\mathbf{R}_i = \mathbf{C}\mathbf{A}^{i-1}\mathbf{G}
\]
where $\mathbf{G} := \sum_{t=1}^{T-1}\mathbf{x}_{t+1}\mathbf{y}_t^T$. From this identity it follows that the block-Toeplitz matrix
\[
\mathbf{T}_{1|i} := \begin{pmatrix}
\mathbf{R}_i     & \mathbf{R}_{i-1} & \cdots & \mathbf{R}_1 \\
\mathbf{R}_{i+1} & \mathbf{R}_i     & \cdots & \mathbf{R}_2 \\
\vdots                 & \vdots                 & \ddots & \vdots             \\
\mathbf{R}_{2i-1}& \mathbf{R}_{2i-2}& \cdots & \mathbf{R}_i
\end{pmatrix}
\]
satisfies
\[
\mathbf{T}_{1|i} \;=\; \underbrace{\begin{pmatrix}\mathbf{C}\\\mathbf{C}\mathbf{A}\\\mathbf{C}\mathbf{A}^2\\\vdots\\\mathbf{C}\mathbf{A}^{i-1}\end{pmatrix}}_{\boldsymbol{\mathcal{O}}_i \,\in\, \mathbb{R}^{li\times n}}\;\;\underbrace{\begin{pmatrix}\mathbf{A}^{i-1}\mathbf{G} & \mathbf{A}^{i-2}\mathbf{G} & \cdots & \mathbf{A}\mathbf{G} & \mathbf{G}\end{pmatrix}}_{\boldsymbol{\mathcal{C}}_i \,\in\, \mathbb{R}^{n\times li}}
\]
where $n$ is the number of modes in the system.

The core idea of SSI-COV is to use SVD to decompose $\mathbf{T}_{1|i} \approx \mathbf{U}\mathbf{S}\mathbf{V}^T = (\mathbf{U}\mathbf{S}^{1/2})(\mathbf{S}^{1/2}\mathbf{V}^T)$ where the equality is approximate as we only keep the top $n$ singular values, and $\mathbf{S}^{1/2}$ denotes the matrix obtained from $\mathbf{S}$ by taking $\sqrt{\cdot}$ of each element.

We then approximate $\mathcal{O}_i \approx \mathbf{U}\mathbf{S}^{1/2}$, which immediately yields an approximation of $\mathbf{C}$ (from the first block of $\mathcal{O}_i$) and a linear system which can be solved for $\mathbf{A}$ (by considering the relationship between blocks of $\mathcal{O}_i$).

Note that one prerequisite for applying SSI-COV is to know in advance the number of modes. Since this is an unknown, implementations typically perform the analysis for multiple values of $n$, and then allow the user to choose the most plausible $n$ through a visualization called a stabilization diagram~\cite{Peeters01022000}.
We opt instead to use MPE plots from FSDD to allow the user to pick $n$ once during setup.

\section{Implementation}\label{sec:practical}

In this section we present our implementation of OMA, showcasing its ease of use and its application to structural health monitoring with a concrete example of a wind turbine project. Our work builds on the open source PyOMA2 package~\cite{pyoma2} by adding a user-friendly web interface which can be used by non-experts with minimal training. Figure~\ref{fig:impl-schematic} depicts the high level organization of our implementation.

\input{figures/impl_schematic.tex}

Key abstractions from Senmos such as sensor channels and sensors (groups of channels) are reused in the context of OMA; each frequency and damping mode is mapped to a sensor channel, and the user is given an option of automatically creating all required channels under a new sensor object. Reusing these abstractions automatically allows the user to apply signal processing algorithms available in Senmos to OMA outputs directly, as well as plot them.

Senmos aggregates data from a large number of heterogenous sources. In practice this means that measurement data often arrives out of order, with a time-varying delay, or not at all. Several complications requiring non-trivial design decisions arise due to the need to handle these issues; all of these are handled by our dispatcher implementation. The database tracks a marker with the end date of the last window processed for each OMA configuration. When the dispatcher runs a new refresh cycle, it calculates which OMA configurations may have new windows to process based on this marker and the window size/boundary configured by the user. Next, candidate windows are handed to a worker pool for processing. The number of candidate windows dispatched per configuration is limited to the last $N$ windows where $N$ is set to a suitable value. The assigned worker collects all measurement data falling inside the window and performs SSI-COV (c.f. Section~\ref{sec:ssi}) on it, aborting if the fill factor is below 10\%.

Since there is no reliable way to distinguish between a period of missing data and a large delay in sending data, the dispatcher also resets the marker of configurations which have fallen behind by more than $M$ days to a more recent date, so that such configurations catch up. A system administrator can manually recompute historical windows which have been skipped due to this design.
